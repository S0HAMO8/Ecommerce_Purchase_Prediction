E-Commerce Customer Purchase Prediction (Logistic Regression)

Requirements: Python 3.9+, pandas, numpy, matplotlib, seaborn, scikit-learn, joblib
  pip install pandas numpy matplotlib seaborn scikit-learn joblib

Run the whole program:
  python ecommerce_purchase_prediction.py
or open Ecommerce_Purchase_Prediction.ipynb in Jupyter and choose Run All.

Keep these files in the same folder: the CSV dataset and iqr_capper.py.
Outputs are written to figures/ (charts) and artifacts/ (model .pkl, cleaned csv, results.json).
